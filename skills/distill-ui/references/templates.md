# ui-skill 铸造模板

五份 reference 的骨架,照模填空。规则:

- 占位符一律 `<尖括号>`;模板里没有任何真实设计值——铸模的内腔,不是浇进去的铁水。
- 业务代码只引语义槽,字面档只活在本文件与 theme 定义里(见 ui-skill-spec 的产出规则)。
- 每张表都是双读者格式:人能通读,AI 能秒查。
