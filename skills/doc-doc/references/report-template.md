# 检测报告模板

报告是检测的交付物，也是改写的闸门：出完报告**停下**，等使用者回复"按建议改"或调整范围，再动手。

填写规则：

- 每个数字标来源：`[实测]`（现场脚本）/ `[未测]`（使用者跳过）。没有第三种。
- 命中必须带原文位置与例句；建议改法具体到句。
- 误报、判读阴性的计数和理由保留，不静默丢弃。
- 整篇分布指标只报值与方向，不强造逐句命中数。

---

## 模板

```markdown
# 读者友好检测报告：<篇名>

体裁：<散文/技术文档/教程/…>｜风格基准：<有则注明来源文档，无则写"无">
规模：<汉字数> 字 / <段数> 段 / <小节数> 节　[实测/未测]

## 一、判据化命中（建议改，等你确认）

### <苦主 1，如：新造名词>
- 命中 <n> 处 [<来源>]，判据标签分布：<0组×a / 1组×b / 2组×c / …>
- 例句（行/段定位）：
  > <原文摘录>
- 建议改法：<具体到句>
- 不改的情况（本篇实际出现）：<列出，如 引语内 2 处已排除>

### <苦主 2 …>（同上结构）

## 二、指纹（带方向解读，不推断文本出自哪个模型）

- 破折号 <n> 处，<密度>/千字 [实测/未测]：GPT 侧偏少 / Opus 侧偏多；可安全改写的 <m> 处默认建议改，保留 <k> 处理由：<…>
- 分号、引号、焦点后置：同上结构

## 三、只报告（默认不改）

- 断句节奏：句长 CV <值> [实测]（人类参考 0.54）/ [未测] 定性印象：<…>
- 排版碎乱：<小节数> 节、小标题 <密度>/千字 [实测/未测]；结构重组需要你明确授权
- 衔接连环：最长 <L> 连环 [实测/模型清点]（≥6 即报告）

## 四、人审区（默认保留，仅列清单）

- 理想化拟人喻体 <n> 处：<清单>——贴切与否模型判不准，由你裁决

## 五、X 级计数（防误改，不会据此动文字）

<设问 n 处 / 序数词小标题 n 处 / 「这意味着」n 处 / …>——实测不是问题或方向已反转。

## 六、未测项

<使用者跳过的计算项清单：指标名 + 未测原因"使用者选择跳过">

---

以上为全部建议。回复"按建议改"，或指出要保留/加改的条目，我再动手。
```

## 复测报告（改写完成后）

同一模板再出一份，并加对照节：

```markdown
## 前后对照

| 指标 | 改前 | 改后 | 人类参考 |
|---|---|---|---|
| <苦主命中数/密度> | <值> [实测] | <值> [实测] | <参考> |

- 改动清单：<每处改动 → 对应苦主与判据>
- 未命中文字逐字保留核对：<通过/异常说明>
- X 级计数变化：<防误改核对>
```

复测的计算项沿用改前的决定：改前实测的项复测仍实测（同一脚本、同一口径），改前未测的项保持未测，不中途换口径。
